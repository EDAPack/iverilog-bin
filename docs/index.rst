iverilog-bin Documentation
==========================

**iverilog-bin** is a portable, pre-built distribution of
`Icarus Verilog <https://steveicarus.github.io/iverilog/>`_ — the open-source
Verilog simulation and synthesis compiler — for Linux
(manylinux 2014 / glibc 2.17+ through manylinux 2.34 / glibc 2.34+).
It provides ready-to-use binaries for compiling and simulating Verilog and
SystemVerilog designs in a single self-contained tarball.
